## 2025-02-20 - [Performance Issue from Engine Status updates]
**Learning:** In a heavily real-time updating React application (like a chess engine sending many progress frames a second), expensive recalculations inside standard variables (like parsing `game.moves()` or deep board scans for check state) inside root component or large layout components will severely tank performance if not memoized, because the components update and re-render many times per second during processing.
**Action:** In React applications containing frequent updating logic (e.g. streaming, web sockets, worker events), always ensure derived state logic that loops or runs expensive library calls is properly memoized via `useMemo` hooks tied specifically to the source-of-truth object that requires it to update.
