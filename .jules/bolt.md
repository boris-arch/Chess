## 2026-11-08 - Expensive O(N) string generation in chess.js\n**Learning:** The `game.fen()` method in the `chess.js` library computes the FEN string by iterating over the board, which is an O(N) operation. Calling this inline inside event handlers, cloning functions, or frequent subscriptions (like engine analysis) introduces unnecessary overhead, especially when a `fen` state variable already holds the pre-computed value.\n**Action:** Always prefer using the existing `fen` state variable (or a `fenRef` to it in closures) over calling `game.fen()` directly.
