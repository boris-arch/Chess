## 2023-11-03 - Memoizing Static SVGs in Grid Games\n**Learning:** In a React-based board game, rendering a 8x8 grid with complex SVGs causes significant overhead if the entire board re-renders on state change. Memoizing the individual piece components prevents unneeded re-renders since most pieces don't move.\n**Action:** Use React.memo for UI elements with simple primitive props that appear repeatedly but change infrequently.
